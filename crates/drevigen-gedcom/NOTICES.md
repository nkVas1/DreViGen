# Third-party data in `drevigen-gedcom`

`src/encoding/tables.rs` is generated by `tools/generate-encoding-tables.mjs` from the published
sources below. The tables are data taken from these sources, not code written from them, so their
terms travel with this crate. Each source is fetched from a pinned location and checked against a
recorded SHA-256 before use.

| Table | Source | Terms |
|---|---|---|
| windows-1250, windows-1251, windows-1252, IBM437, IBM850, IBM866 | Microsoft's tables in Unicode's mapping directory, `unicode.org/Public/MAPPINGS/VENDORS/MICSFT/` | Unicode License v3 |
| Canonical combining classes and compositions | Unicode Character Database 16.0.0: `UnicodeData.txt`, `CompositionExclusions.txt` | Unicode License v3 |
| Mac OS Roman | WHATWG Encoding Standard, `index-macintosh.txt`. Apple's table in Unicode's mapping directory matches it byte for byte, but Apple reserves all rights to it, so this copy is taken from WHATWG | CC BY 4.0 |
| ANSEL | MARC-8 Extended Latin as the Library of Congress maps it to Unicode, in pymarc's transcription `pymarc/marc8_mapping.py` at commit `738b200f` | BSD-2-Clause |
| ANSEL, GEDCOM's additions | *The GEDCOM Standard*, Release 5.5, Appendix C (the characters marked "LDS extension"), and Release 5.5.1, Appendix C (es zet) | Facts from the specification |

by WHATWG (Apple, Google, Mozilla, Microsoft), licensed under the
